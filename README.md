# BTC · ETH 일봉 매매 / v14

현재 기본 전략은 BTC/ETH 공통 DMI(14) 교차 + 일봉 종가 10% 손절입니다.

- +DI가 −DI를 상향교차하면 매수, 하향교차하면 매도.
- 확정 종가 ≤ 모의 매수가 × 90%이면 손절 매도. 모의 매수가는 매수 신호 다음 일봉 시가에 0.03% 슬리피지를 반영합니다.
- 매수·매도는 번갈아 발생합니다. 손절 후에는 다음 DMI 상향교차까지 기다립니다.
- 강력 표시: 해당 방향 DI 우세, ADX(14)≥20 및 전일 대비 상승, 우세 DI 격차 확대. 표시·경고만 변경하며 거래 신호는 제한하지 않습니다.
- 일반 매도 이후 강력매도 조건이 처음 충족되면 다음 매수 전까지 추가 경고 1회. 처음부터 강력 조건인 매도에는 재경고 없음. 매수 이후 강력매수 추가 알림 없음.
- 추가 경고는 `sig=관망`, `alert_event=True`, `upgrade_warning=True`, `event_kind=추가 매도 경고`이며 모의 포지션을 변경하지 않습니다. 이미 매도했다면 추가 거래 불필요.
- RSI·스토캐스틱·EMA·MACD·거래량은 현재 기본 판단에 사용하지 않습니다. 과거 연구 함수/보고서는 오프라인 비교를 위해 소스에 남아 있습니다.

확정 일봉만 사용합니다(KST 09:00 마감). 앱 열린 동안 4시간 확인, 앱 외 알림은 별도 예약 모니터링. 자동 주문이나 실제 계좌 연동 없음.

백테스트: 수수료 0.05%/편도, 슬리피지 0.03%/편도, 확정 신호 다음 일봉 시가 체결, 최소 보유 24시간, 미청산 평가액에 예상 청산비용 포함. 종가 손절은 손실을 정확히 10%로 제한하지 않으며 과거 성과는 미래 수익을 보장하지 않습니다.

검증: `python -m unittest test_strategy.py -q` (19개 통과). 교차·손절·강력 경고 중복/초기 강력매도/다음 매수 후 경고 초기화/미래 데이터 미사용/두 코인·기간별 화면·데이터 오류 처리 검증.
